# Store listings

Text and images for the Chrome Web Store, Microsoft Edge Add-ons and Firefox Add-ons (AMO). Images in this folder are generated by `pnpm assets:store`.

## Shared

**Name:** URLy

**Short description** (Chrome limit 132 characters, 88 used):

> Copy the URLs of your open tabs and open every link in pasted text, in one click.

**Detailed description:**

> URLy moves links in and out of your tabs with as few clicks as possible.
>
> Copy
>
> - Copy the URLs of every tab in the current window, all windows, or only the tabs you selected.
> - Formats: plain URLs, Markdown links, title and URL, HTML links (pastes as real links in Docs and email), CSV, JSON, or your own template with placeholders like {title}, {url}, {domain} and {index}.
> - Remove tracking parameters such as utm_source and fbclid.
> - See a live preview of the copied text before you copy.
> - Press Alt+Shift+C to copy without opening the popup, or right-click the toolbar icon to copy in any format.
> - Internal browser pages and duplicate URLs are skipped.
>
> Open
>
> - Paste any text: notes, chat messages, emails. URLy finds every link and opens them as background tabs in order, or in a new window.
> - Select text on a page, right-click and choose "Open links in selection".
> - URLy asks before opening more than 20 tabs.
>
> Private by design: no data collection, no network requests, no clipboard reading. Open source under the MIT license.
>
> Shortcuts: Alt+Shift+U opens URLy, Alt+Shift+C copies tab URLs. Change them in your browser's extension shortcut settings.

## Chrome Web Store

**Category:** Tools. **Language:** English.

**Single purpose:**

> Copy the URLs of open tabs to the clipboard and open links found in text the user provides.

**Permission justifications:**

| Permission       | Justification                                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------------------------------- |
| `tabs`           | Reads the URLs and titles of open tabs so they can be copied, and opens new tabs for links the user provides. |
| `storage`        | Saves the user's chosen format, template and options locally.                                                 |
| `contextMenus`   | Adds "Copy tab URLs" to the toolbar icon menu and "Open links in selection" to the page menu.                 |
| `clipboardWrite` | Writes the copied URLs to the clipboard when the user presses the copy shortcut.                              |
| `offscreen`      | Service workers cannot access the clipboard; an offscreen document writes the copied URLs for the shortcut.   |

**Remote code:** No, all code is packaged with the extension.

**Data usage:** collects none of the listed data types. Certify all three disclosures (no selling, no unrelated use, no creditworthiness use).

## Firefox Add-ons (AMO)

Upload `urly-<version>-firefox.zip`.

**Summary** (limit 250 characters):

> Copy the URLs of your open tabs as plain text, Markdown, HTML, CSV, JSON or a custom template, and open every link in pasted text. No tracking, no data collection.

**Categories:** Tabs, Productivity. **Tags:** tabs, urls, links, copy, clipboard, markdown.

**License:** MIT. **Privacy policy:** paste `PRIVACY.md`.

**Source code:** required, because the build is bundled and minified. Upload `urly-<version>-sources.zip`, which `pnpm zip:firefox` creates next to the Firefox zip.

**Notes for reviewers:**

> Built with WXT (Vite). To reproduce from the sources zip: Node 24, pnpm 12, `pnpm install --frozen-lockfile && pnpm zip:firefox`, output in `.output/`. The extension makes no network requests.
